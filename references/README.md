# Design references

Drop reference images here — posts, posters, layouts, anything that matches (or deliberately misses) the look you want.

Images pasted into chat aren't saved anywhere, so a later session can't look at them again. Files in this folder can be opened and studied directly.

**Useful to include:**

- Things you like, and things you *don't* — the dislikes pin down the boundary far better than more good examples do.
- A word or two in the filename when it's easy: `like-big-type.jpg`, `too-busy.png`. Not required.

What gets learned from these is written into `.claude/skills/social-design/SKILL.md`.
